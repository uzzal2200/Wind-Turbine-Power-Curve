## Overview

DA-PINN embeds aerodynamic physics constraints — Betz limit compliance, power coefficient (Cₚ) bounds, and monotonicity regularization — directly into the training loss of a multi-layer perceptron, augmented by a health conditioning vector for degradation-severity-aware prediction.

Evaluated on the **Kelmarsh Wind Farm SCADA dataset** (six Senvion MM92 turbines, 2016–2024, ~2.85 M samples):

| 📊 Metric                  | 🎯 DA-PINN   | 📈 Best Baseline | ✨ Improvement |
| -------------------------- | ------------ | ---------------- | -------------- |
| 📉 MAE (kW)                | **72**       | 98               | −26.5 %        |
| 📉 RMSE (kW)               | **95**       | 131              | −27.5 %        |
| 📊 R² Score                | **0.975**    | 0.953            | +0.022         |
| 📈 MAPE (%)                | **6.6**      | 8.9              | −2.3 pp        |
| ⚡ Betz Violation Rate (%) | **0.3**      | 6.7              | −22×           |
| ❄️ Icing Early Warning     | **19 h avg** | 51 % recall      | —              |

### Key Contributions

- **Composite physics loss** — Betz limit penalty (𝓛_Betz), Cₚ constraint (𝓛_Cp), monotonicity regularisation (𝓛_smooth)
- **Proxy labeling protocol** — Healthy / Mild / Severe icing labels from SCADA-native signals, validated against 61 confirmed icing events (precision 0.84, recall 0.91)
- **Health conditioning vector** — h(t) = [ΔT_blade, PR_6h, AI_pitch]ᵀ for severity-aware inference without per-class models
- **CUSUM physics residual monitor** — 19 h average icing early warning on the Kelmarsh dataset

## Environment Setup

### Prerequisites

- Python 3.10 or higher
- pip 23+
- (Optional) CUDA 11.8+ for GPU training

### 1 — Clone the repository

```bash
git clone https://github.com/uzzal2200/Physics-Informed-Neural-Network-for-Wind-Turbine-Power-Curve-Modeling-Under-Icing-and-Degradation.git

```

### 2 — Create a virtual environment

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
```

### 3 — Install dependencies

```bash
pip install -r requirements.txt
```

### 4 — Download the Kelmarsh dataset

```bash
# Requires zenodo_get or manual download from:
# https://zenodo.org/record/5841834
pip install zenodo-get
zenodo_get 5841834 -o data/raw/
```

## Quick Start

### Train DA-PINN

```bash
python train.py --config configs/config.yaml
```

### Evaluate on test set (2023–2024)

```bash
python evaluate.py --config configs/config.yaml --checkpoint outputs/checkpoints/best_model.pt
```

### Run CUSUM icing monitor on new SCADA feed

```bash
python monitor.py --config configs/config.yaml --checkpoint outputs/checkpoints/best_model.pt --input data/raw/new_scada.csv
```

## Configuration

All hyperparameters live in `configs/config.yaml`. Key fields:

```yaml
physics:
  lambda_betz: 0.8
  lambda_cp: 0.5
  lambda_smooth: 0.3
  rho: 1.225 # Air density kg/m³
  rotor_area: 6647.61 # π·(46)² m²  (MM92, 92 m diameter)

model:
  hidden_dims: [64, 128, 64]
  dropout: 0.0

training:
  lr: 1.0e-3
  batch_size: 256
  max_epochs: 200
  patience: 20

cusum:
  k_factor: 0.5 # Allowance = k·σ₀
  h_factor: 4.0 # Alert threshold = h·σ₀
```

## Reproducing Paper Results

```bash
# 1. Preprocess raw SCADA
python -m src.preprocessing.cleaner

# 2. Generate proxy labels
python -m src.preprocessing.proxy_labeler

# 3. Train all models (DA-PINN + 5 baselines)
python train.py --config configs/config.yaml --all-baselines

# 4. Evaluate and generate tables
python evaluate.py --config configs/config.yaml --all --save-tables

# 5. Calibrate and run CUSUM monitor
python monitor.py --config configs/config.yaml --calibrate
```
